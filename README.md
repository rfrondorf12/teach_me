# Teach Me Hub 👾

Interactive study workspace with formatted lecture notes and 3D spaced repetition flashcard decks, generated directly from Obsidian study materials.

Hosted live on GitHub Pages.

## Site Structure

```text
teach_me/
├── index.html                           (Homepage & Dashboard — GitHub Pages entry point)
├── folders.html                         (Subject Directory: Art, Artificial Intelligence, etc.)
├── note-adobe-professional.html         (Study Notes: Adobe Certified Professional)
├── flashcards-adobe-professional.html   (Interactive 44-card study deck: Adobe)
├── note-ai-for-app-building.html        (Study Notes: AI for App Building)
├── flashcards-ai-for-app-building.html  (Interactive 15-card study deck: AI)
├── style.css                            (Central Neo-Brutalist design stylesheet)
└── README.md
```

## Features

- **Responsive Top Navbar:** Clean, uncluttered global navigation (`Dashboard` and `Subject Folders`).
- **Subject Directory:** Organized by topic folders (Art, Artificial Intelligence, Science, Math, Literature, Language, History).
- **Interactive 3D Flashcards:** Spaced repetition decks featuring single-click 3D flipping, hint reveals, shuffle mode, star tags, and status filtering (`New`, `Still Learning`, `Mastered`).
- **Progress Persistence:** Automatic mastery state preservation in the browser via `localStorage`.
- **Formatted Notes:** Notes formatted with bold vocabulary definitions, green equation highlights, pink tool/menu pathways, and bidirectional links to study decks.
