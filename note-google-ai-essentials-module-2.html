1. Foundational AI Tool Types

  • Gen AI - AI that can generate new content, like text, images, or other media.
    • Can use for crafting a compelling company profile or creating detailed product descriptions.
    • Can translate content into multiple languages.
    • Can support research on relevant business topics by summarizing data for easy understanding.
    • Can use for image generation for branding, video generation, and code generation.
  • Stand alone AI tool - AI-powered software that’s designed to be used on its own.
    • Accessed online or through an app.
    • Ex.: Speeko → AI speech coach for job interview practice; gives personalized challenges.
  • Integrated AI feature - A built-in enhancement to a particular piece of software.
    • Ex.: Neural Filters → Adobe Photoshop.
  • Custom AI Solution - An application that’s tailor made to solve a specific problem.
    • Ex.: Detecting sepsis.
  • AI Model - A computer program trained on a set of data to recognize patterns and perform specific tasks.
    • AI model = engine, AI tool = car
  • AI Agent - An AI-powered tool that can autonomously perform tasks with little human oversight.
    • Ex.: Automatically respond to emails, post content on socials, or monitor computer networks.
    • Some tools incorporate multiple AI models working together to perform a wider range of tasks.

2. How AI Models Are Made: The 7-Step Training Process

AI tools are built on top of AI models. The typical process includes:

  1. Define the problem to be solved - AI designers want to predict rain to help people stay dry when commuting. They consider an AI tool’s features and limitations before identifying an AI solution.
  2. Collect relevant training data - Gather historical data of days when it rained and days when it didn’t rain over the past 50 years.
  3. Prep the data for training - Label important features like outdoor temp, humidity, and air pressure, noting whether it rained.
    • Common practice: separate data into a training set to use during training and a validation set to test after training is complete.
  4. Train the model - Apply ML programs to the prepared training data; as programs analyze data, they begin recognizing patterns indicating the likelihood of rainfall.
  5. Evaluate the model - Use the prepped validation set to assess the model's ability to predict accurately and reliably; reveals issues like insufficient or biased training data. Proceed once the model performs well.
  6. Deploy the model - When satisfied with model performance, deploy the model inside an AI tool.
    *Designers and engineers repeat each step as many times as necessary, adjusting until they create the best model possible.
  7. User Interaction - Once users interact with a model, it may encounter new challenges. Designers must continuously collect and monitor feedback to maintain reliable performance and ID areas for improvement.

3. Using AI in Work & Workflow Integration

  • Prompt - Text input that provides instructions to the AI model on how to generate output.
  • Text & content GenAI - Built on Large Language Models (LLMs) trained on vast amounts of text and data.
  • Code Gen AI tools - Often described as an “AI pair programmer” → specialized for software development.
  • Image & media generative tools - Use technology known as diffusion models, which generate new content from prompts.

Integrating AI into Workflows

  • Native features - Built-in AI capabilities within existing applications.
  • Browser extensions - Tools added to web browsers allowing AI to assist across wide web-based apps.
  • Dedicated applications - Standalone tools used as a “thinking partner” by copying/pasting text.
  • Automation platforms - Connect tools across different apps to create automated workflows without code (ex.: summarizing an email with AI and adding it to a to-do list).

4 Steps to Getting Started

  1. ID bottlenecks - Pinpoint the most time-consuming or repetitive daily tasks.
  2. Start small - Focus on one bottleneck and find a single AI tool to master for that specific task.
  3. Build a habit - Make a conscious effort to use the chosen tool whenever performing that task until it is a reflex.
  4. Evaluate & expand - Assess impact after 1–2 weeks: how much time was saved, and did work quality improve?

4. Human-in-the-Loop & Responsible AI

  • Human in the loop approach - A combination of machine and human intelligence to train, use, verify, and refine AI models. Should always be taken when using AI tools.
  • Responsible AI - The principle of developing and using AI ethically, with the intent of benefiting people and society while avoiding harm. Includes managing limitations like the knowledge cutoff.
  • Knowledge cutoff - The concept that an AI model is trained at a specific point in time, having no knowledge of events or information after that date.
    • Well-designed tools recognize limitations and respond accordingly.
    • Tools that do not recognize limitations may hallucinate an answer.

5. GenAI Assessment for a Task

Three guiding questions to determine if GenAI is up for a task:

  • Is the task generative?
  • Can the task be iterated on to achieve the best outcome?
  • Are there resources to provide adequate human oversight?

6. Workplace AI Applications

  • Spreadsheets: Use Gemini with Google Sheets or Copilot with Excel; or upload sheets and data to ask platforms for direct analysis.
  • AI notetakers: Use in Google Meet or Zoom to list priorities/immediate action items and draft follow-up emails.
